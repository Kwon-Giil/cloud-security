# Cloud Security Self-Study

QA 실무 경험을 기반으로 **Cloud Security · DevSecOps · Security QA** 영역으로 역량을 확장하기 위한 자기주도 학습 프로젝트.

단순한 강의 수강이나 기술 경험에 그치지 않고, **이론 → 실습 → 검증 → 기록**의 과정을 반복하며 학습 과정과 결과를 GitHub에 축적한다.

## Goal

기존 QA 경험을 기반으로 웹 보안, 클라우드, 컨테이너, DevSecOps, Security QA 영역을 단계적으로 학습하고, 최종적으로 이를 하나의 보안 검증 및 자동화 프로젝트로 연결한다.

## Curriculum

| 기간 | 학습 영역 |
|---|---|
| **1개월차** | Foundation — Linux · Network · Web · Docker |
| **2개월차** | Web Security — OWASP · Burp Suite · Security Testing |
| **3개월차** | Cloud & IaC — AWS · IAM · VPC · Terraform |
| **4개월차** | Cloud Security — Architecture · IAM · Network · Validation |
| **5개월차** | Container Security — Docker · Kubernetes · Trivy |
| **6개월차** | DevSecOps — CI/CD · SAST/SCA · Secret Scanning · Security Gate |
| **7개월차** | Security QA — API · Playwright · Authentication/Authorization |
| **8개월차** | Integration — Cloud Security · DevSecOps · Security QA |

> 세부 학습 계획은 실제 학습 진행 상황과 평가 결과에 따라 조정한다.

## Learning Approach

학습은 다음 흐름을 기본으로 진행.

**학습 목표 → 관련 개념 학습 → 이해 확인 → 실습 / 시뮬레이션 → 누적 평가 → 기록**

서로 연관된 개념은 지나치게 작은 단위로 분리하지 않고, 하나의 시스템·흐름·문제를 중심으로 연결하여 학습.

명령어나 스크립트의 실행 성공만으로 학습 완료를 판단하지 않고, **직접 수행하고 결과를 설명할 수 있는지** 확인.

평가는 개별 개념 직후에 반복하기보다 일정 범위의 학습이 누적된 후 이전 내용을 회상하고 연결할 수 있는 방식으로 진행.
