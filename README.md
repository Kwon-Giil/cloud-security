# cloud-security
해당 폴더는 테스트 자동화 및 클라우드 보안을 학습을 위한 학습용 폴더입니다.

전체 학습 목표: QA 실무 경험을 기반으로 Cloud Security, DevSecOps, Security QA 영역으로 역량 확장.

단순한 강의 수강이나 기술 나열을 목표로 하지 않고, 이론 학습 → 실습 → 검증 → 기록을 반복하며 학습 과정과 결과를 GitHub에 축적

##커리큘럼
1개월차: Foundation	Linux · Network · Web · Docker
2개월차: Web Security	HTTP · OWASP · Burp Suite · Security Testing
3개월차: Cloud & IaC	AWS · IAM · VPC · Terraform
4개월차: Cloud Security	Cloud Security · IaC Security · Security Validation
5개월차: Container Security	Docker · Kubernetes · Trivy · K8s Security
6개월차: DevSecOps	GitHub Actions · SAST/SCA · Secret Scanning · Security Gate
7개월차: Security QA	Playwright · API · Authentication/Authorization · Security E2E
8개월차: Integration	Cloud Security + DevSecOps + Security QA 통합 프로젝트

세부 주제와 주간 학습 계획은 학습 진행 상황과 평가 결과에 따라 조정.

하나의 학습 단위는 관련 개념을 지나치게 세분화하지 않고, 실제 시스템의 흐름·문제·수행 목표를 중심으로 구성.

## 러닝 & 코칭

Learning Approach

학습은 다음의 흐름을 기본으로 진행한다.

학습 목표 → 관련 개념 학습 → 이해 확인 → 실습/시뮬레이션 → 누적 평가 → 기록

관련된 개념은 지나치게 잘게 분리하지 않고 하나의 시스템, 흐름 또는 문제를 중심으로 연결.

개별 개념을 암기하거나 명령어를 실행하는 것만으로 학습 완료를 판단하지 않고, 직접 수행하고 결과를 설명할 수 있는지를 확인.

평가는 매 학습 단위 직후에 반복하지 않고, 일정 범위의 학습이 누적된 후 이전 내용을 회상하고 연결할 수 있는 방식으로 진행.

Final Goal
