# Linux 기본 명령어

**Date:** 2026-09-22
**Category:** Linux / Fundamentals

## 1. 학습 목표

Linux 환경에서 자주 사용하는 기본 명령어와 각 명령어의 역할을 이해하고, 어떤 상황에서 어떤 명령어를 사용하는지 익힌다.

향후 Docker, AWS, Kubernetes 등의 환경에서 Linux CLI를 직접 다루기 위한 기초를 마련한다.

---

## 2. 학습 내용

### 2.1 Linux CLI 기본 이해

Linux에서는 터미널을 통해 명령어를 입력하여 시스템을 조작할 수 있다.

오늘은 개별 명령어를 깊게 실습하기보다는 **어떤 명령어가 존재하고, 각각 어떤 상황에서 사용하는지**를 중심으로 학습했다.

기본적으로 명령어는 다음과 같이 옵션과 인자를 조합하여 사용할 수 있다.

```text
명령어
  ↓
옵션
  ↓
인자
  ↓
실행
```

같은 명령어라도 옵션과 인자에 따라 확인하거나 수행하는 작업이 달라질 수 있음을 확인했다.

### 2.2 주요 기본 명령어

Linux 환경에서 자주 사용되는 기본 명령어의 용도와 사용 상황을 확인했다.

| 명령어     | 주요 용도                 |
| ------- | --------------------- |
| `pwd`   | 현재 작업 디렉터리 확인         |
| `ls`    | 파일 및 디렉터리 목록 확인       |
| `cd`    | 작업 디렉터리 이동            |
| `mkdir` | 디렉터리 생성               |
| `touch` | 파일 생성                 |
| `cp`    | 파일 및 디렉터리 복사          |
| `mv`    | 파일 및 디렉터리 이동 또는 이름 변경 |
| `rm`    | 파일 및 디렉터리 삭제          |
| `cat`   | 파일 내용 확인              |
| `less`  | 파일 내용을 페이지 단위로 확인     |
| `grep`  | 특정 문자열 검색             |
| `find`  | 조건에 맞는 파일 및 디렉터리 검색   |
| `man`   | 명령어 사용법 및 옵션 확인       |
| `sudo`  | 관리자 권한으로 명령 실행        |

오늘은 각 명령어를 반복적으로 사용하여 숙련하는 것보다, **필요한 작업에 맞는 명령어를 선택할 수 있도록 역할을 파악하는 것**에 중점을 둠.

### 2.3 실습 환경에 대한 확인

Nginx에 HTTPS를 적용하고 무료 SSL 인증서를 발급한 뒤 자동 갱신까지 설정하는 실습도 확인했으나, 해당 과정은 공인 IP와 도메인 연결 등 별도의 환경 구성이 필요하다.

현재 학습 환경에서는 이를 무리하게 구성하기보다 Linux 기본 명령어와 시스템 사용 방법을 먼저 익히는 방향으로 정리함.

## 3. Hands-on

오늘은 개별 명령어를 반복하여 숙련하는 실습보다는 **명령어의 종류와 용도를 파악하는 학습**을 중심으로 진행했다.

| 학습 영역    | 확인 내용                        |
| -------- | ---------------------------- |
| 파일/디렉터리  | 경로 확인, 이동, 생성·복사·이동·삭제       |

| 방화벽      | Linux 환경에서 방화벽 설정 및 관리 방식 확인 |

## 5. Assessment

오늘 학습한 Linux 기본 명령어를 역할별로 구분하고, 필요한 작업에 어떤 명령어를 사용하는지 설명할 수 있는지 확인함.
