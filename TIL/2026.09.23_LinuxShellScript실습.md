# Linux Bash Shell Scripting

**Date:** 2026-09-23
**Category:** Linux / Bash / Automation

## 1. 학습 목표

Linux 기본 명령어를 복습하고 Bash Shell Script를 직접 작성·실행.

---

## 2. 학습 내용

### 2.1 Linux 기본 명령어 복습

기존에 학습한 Linux 기본 명령어를 간단히 복습하고, 이후 Shell Script 작성에 필요한 명령어를 다시 확인함.

### 2.2 Bash Shell Script

Linux 명령어를 여러 개 묶어 하나의 Script로 실행할 수 있는 기본적인 흐름을 확인함.

백업용 Shell Script를 작성하고 실행 권한을 부여한 뒤 실행하여 결과 파일이 생성되는지 확인함.

## 4. Troubleshooting

### 4.1 Nano 편집기

`nano`에서 파일을 수정하고 저장·종료하는 방법을 몰라 작업 중 혼선이 발생했음.

### 4.2 경로 확인

실습 디렉터리와 파일 위치를 찾는 과정에서 경로를 혼동하여 현재 위치와 파일 경로를 다시 확인했다.

### 4.3 `chmod +x` 후 권한 표시

`chmod +x` 실행 후 파일 권한이 다음과 같이 표시되었음.

```text
-rwxrwxrwx
```

WSL에서 Windows 파일시스템 경로를 사용하고 있었기 때문에 Linux 파일시스템에서와 다른 권한 표시가 나타날 수 있음을 확인함.

### 4.4 비밀번호 입력

비밀번호 입력 시 화면에 글자나 `*`가 표시되지 않아 입력되지 않는 것으로 생각했음.

터미널에서는 비밀번호 입력 내용을 화면에 표시하지 않는 것이 일반적인 동작임을 확인함.
